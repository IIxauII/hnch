# packages/client

Angular + Ionic + Capacitor mobile/PWA client.

Before writing or reviewing code here, consult:

- `docs/angular.md` — Angular + TypeScript conventions: signals, standalone components, control-flow syntax, accessibility baseline, house rules.
- `docs/ionic.md` — Ionic conventions: platform mode, class-based dark-mode/theming via `ThemeService`, half-sheet modal pattern, component imports, icons, safe areas.

Do not edit `packages/shared`, `packages/relay`, or `packages/e2e` from client work without cause.
